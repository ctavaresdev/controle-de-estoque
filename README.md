# 📦 Controle de Estoque em Python

Projeto desenvolvido para praticar lógica de programação, estruturas de dados e organização de código em Python.

## 🚀 Funcionalidades

- Adicionar produtos ao estoque
- Registrar entrada de mercadorias
- Registrar saída de mercadorias
- Listar todos os produtos cadastrados
- Validação de estoque insuficiente
- Menu interativo via terminal

## 🛠️ Tecnologias Utilizadas

- Python 3

## 📂 Estrutura do Projeto

- Cadastro de produtos
- Controle de quantidade em estoque
- Atualização automática das entradas e saídas
- Exibição do estoque atual

## 🎯 Objetivo

Este projeto foi criado com fins de estudo para desenvolver habilidades em:

- Lógica de programação
- Funções
- Estruturas condicionais
- Laços de repetição
- Dicionários
- Organização de código

## ▶️ Como Executar

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta do projeto:

```bash
cd nome-do-projeto
```

3. Execute o arquivo Python:

```bash
python controle_estoque.py
```
